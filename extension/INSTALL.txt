Hiven for Chrome — v0.1.1

1. Unzip. You should see a folder named hiven.
2. Chrome → Extensions → Developer mode.
3. Load unpacked.
4. Select the hiven folder (manifest.json + icons/ must be inside it).

Website: https://matthewcodergamer.github.io/Hiven/
Source: https://github.com/matthewcodergamer/Hiven

Hiven will not extract YouTube, defeat DRM, or bypass access controls.
