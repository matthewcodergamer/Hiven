Hiven.

Detect accessible media. Download it when the site and format allow. Watch for VPN exposure.

Download for Chrome View source
  1. Unzip. Open the folder named hiven.
  2. Chrome → Extensions → turn on Developer mode.
  3. Load unpacked, and select that folder (it contains manifest.json and icons).
  4. Click the Hiven icon, then Scan this tab.

Hiven will not extract YouTube, defeat DRM, or bypass access controls. Detected is not the same as downloadable. v0.1 is not on the Chrome Web Store.
