Install

  1. Download the zip. Unzip. Open the folder named hiven.
  2. Chrome → Extensions → Developer mode.
  3. Load unpacked, and select that folder (manifest.json and icons inside).
  4. Click Hiven. Scan this tab. Or pin your IP under Protection.
